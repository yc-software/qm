# Organization design system

This gallery preserves the full component vocabulary from the original QM admin Design library. Use semantic tokens and the bundled org-design.css, with system sans-serif for interface text and a serif brand wordmark. Surfaces are flat: use borders and spacing, without shadows.

Use one primary action per view. The component classes are button.primary, button.danger, .badge, .pill, .status, .meta-chip, .identity-chip, .card, .notebox, .empty, .setting-toggle, .shell-tabs, .segmented, .tablewrap, .kpis, and .dist. The gallery shows their variants and intended uses. Labels sit above fields, hints below, and save status beside the action.

Apply personal or scope customizations where supplied. Explicit app instructions and an existing app's intentional design take precedence. Updating this reference does not automatically restyle published apps.
